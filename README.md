# Промпт, паяльник, три ствола

Сборник игр для ESP32. В салуне можно сыграть в тетрис с заказами шахты или в пин-понг против компьютера. Сапёр пока в разработке.

## Запуск на плате ESP32

1. Установите [ESP-IDF 5.5.1 для Windows](https://dl.espressif.com/dl/esp-idf/) и откройте терминал ESP-IDF. Разверните окно, чтобы поместилось **100×40 символов**.
2. Подключите плату с ESP32 к компьютеру USB-кабелем с передачей данных. Найдите её COM-порт в «Диспетчере устройств» в разделе «Порты (COM и LPT)».
3. Скачайте проект и прошейте плату. Замените `COM5` на порт вашей платы.

   ```powershell
   git clone https://github.com/disunchik/gaming_mps.git
   cd gaming_mps
   idf.py -p COM5 flash monitor
   ```

4. Когда появится меню, выберите игру стрелками и нажмите Enter. В настройках меняйте сложность клавишами ←/→, затем выберите «Начать игру».

Если меню не появилось после прошивки, нажмите **EN** или **RESET** на плате. Если порт занят, закройте программу, которая его использует. Чтобы выйти из IDF Monitor, нажмите **Ctrl+]**.

## Управление и проверка

В IDF Monitor для буквенных клавиш используйте английскую раскладку.

- **Тетрис.** ←/→ сдвигают фигуру, ↑ поворачивает, ↓ ускоряет падение. Соберите полный ряд и проверьте, что он исчез и прибавились очки.
- **Пин-понг.** ←/→ двигают ракетку. Разыграйте очко и проверьте счёт.
- **Общие клавиши.** P ставит на паузу и продолжает игру, R повторяет партию с теми же условиями, Q или Esc возвращает в меню.

Чтобы повторить старт другой партии, выберите «Играть по коду», введите код P2 с игрового экрана и нажмите Enter.

## Запуск в эмуляторе

В папке проекта установите QEMU из терминала ESP-IDF.

```powershell
python "$env:IDF_PATH\tools\idf_tools.py" install qemu-xtensa
```

Откройте новый терминал ESP-IDF, перейдите в папку проекта и запустите `python tools/run.py`. Для выхода нажмите **F10**.
