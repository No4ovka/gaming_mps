# Сапёр

Выберите «Сапёр» в общем меню, затем сложность, размер и «Начать игру».
Таблица числа мин соответствует заданию.

| Размер | Лёгкая | Средняя | Сложная |
| --- | ---: | ---: | ---: |
| 8×8 | 6 | 10 | 13 |
| 10×10 | 10 | 15 | 20 |
| 12×12 | 14 | 22 | 29 |
| 14×14 | 20 | 29 | 39 |
| 16×16 | 26 | 38 | 51 |

Стрелки двигают курсор. ЛКМ, Enter и пробел открывают клетку. ПКМ и F ставят
и снимают флаг на закрытой клетке. Флаг защищает её от открытия. Первое открытие
безопасно, пустая область раскрывается вместе с числовой границей.
При наведении на открытую цифру подсвечиваются её закрытые соседи.
На панели видно, сколько флагов не хватает или когда можно раскрывать.
Если рядом отмечено ровно столько флагов, сколько показывает цифра,
нажмите на неё, чтобы раскрыть остальных соседей. Ошибочный флаг
может привести к взрыву. Для победы откройте все безопасные клетки.

Таймер запускается с первого открытия и останавливается на паузе и после
завершения партии. P ставит игру на паузу, Q возвращает в меню. R воспроизводит
раскладку и первый ход, а после победы на уровнях 1–4 оболочка предлагает
следующий размер. C копирует текущий P2 после первого открытия в Windows.
Старый P1 можно ввести через пункт «Играть по коду».

Класс `Minesweeper` реализует пять методов `Game`. Для прежнего seed и первого
хода частичное перемешивание кандидатов даёт ту же раскладку. Очередь раскрытия
хранит только найденные нулевые клетки. Координаты мыши модуля уже локальны.
Обе символьные половины клетки переводятся в один логический столбец.

## Проверка

В корне проекта в терминале ESP-IDF v5.5.1 соберите прошивку и запустите тест.

```powershell
idf.py -DIDF_TARGET=esp32 build
python games/minesweeper/tests/qemu_check.py
```

Тест использует клавиши, мышь и известную раскладку. Он проверяет оба формата
кодирования, повтор, подсветку и быстрое раскрытие, победу, взрыв
и переход на следующий размер.

Для проверки механики на компьютере с GCC выполните из корня в Bash:

```bash
mkdir -p build-host
g++ -std=c++17 -Wall -Wextra -Werror -I common -I games/minesweeper \
  games/minesweeper/tests/mechanics.cpp games/minesweeper/minesweeper.cpp \
  common/{screen,menu,code}.cpp -o build-host/minesweeper-mechanics
./build-host/minesweeper-mechanics
```

Общий `tools/smoke.py` из базового коммита проверяет надпись старой заглушки
в игровой области. Для проверки Сапёра используйте сценарий этого модуля.
