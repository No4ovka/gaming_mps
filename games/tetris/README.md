# Тетрис

Модуль работает в общей прошивке ESP32. Поле 10×20, семь фигур, партия длится до
блокировки появления следующей фигуры. Стрелки или WASD двигают и поворачивают
фигуру. Вниз опускает её на один ряд и начинает новый интервал падения. Если ряд
занят или достигнуто дно, следующий шаг вниз фиксирует фигуру. Пауза, повтор
с тем же seed и возврат в меню обслуживаются общей оболочкой.

- Начальный интервал падения составляет 1200, 950 или 740 мс на лёгкой, средней
  или сложной сложности.
- Одновременная очистка одной, двух, трёх или четырёх линий даёт 100, 300, 500
  или 800 очков.
- Фигуры выдаются семёрками через перемешивание Фишера — Йетса. Локальный
  32-битный генератор стартует с `Settings.seed`, включая ноль. На каждый вызов
  он прибавляет `0x9e3779b9` к состоянию и перемешивает биты результата финализатором
  MurmurHash3. Отрисовка и ввод вне игровых команд генератор не трогают.
- Для поворота проверяются позиция на месте, смещения на одну и две клетки
  влево или вправо, затем смещения вверх. На доске нет скрытых строк.

Проверки механики можно собрать из корня репозитория компилятором C++17 для ПК.

```sh
mkdir -p artifacts
g++ -std=c++17 -Wall -Wextra -Werror -Icommon -Igames/tetris \
    games/tetris/tests/rules.cpp games/tetris/tetris.cpp common/screen.cpp \
    -o artifacts/tetris-rules
./artifacts/tetris-rules
```

В активированной среде ESP-IDF отдельная проверка запускает прошивку в QEMU
и подаёт команды по UART. Кадры сохраняются в `artifacts/screens/`.

```powershell
idf.py -DIDF_TARGET=esp32 build
python games/tetris/tests/qemu_smoke.py
```
